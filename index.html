Didn't ask for everything on the card?

For each period, check off anything students weren't told to do this time. Claude won't take points off for it or list it as a grow. Only this assignment changes. The quest cards stay the same.

Post to Google Classroom

Creates the assignment in each period's Classroom class, using the title, points, and that period's quest from above. It goes through the same Rubric Mailer script as Email rubrics (Export and email tab), so connect that first.

Turn on Classroom in your mailer script (one time)
  1. Open your Rubric Mailer project at script.google.com. Copy the script below and paste it over the old code, then change the SECRET line back to your same secret phrase. Click Save.
  2. Click + next to Services, pick Google Classroom API, and click Add.
  3. In the function menu at the top, pick setupClassroom and click Run. Approve the Classroom permissions when Google asks.
  4. Deploy, then Manage deployments. Click the pencil, set Version to New version, and click Deploy. The web app URL stays the same.

Email keeps working, and the rubric grader can use this same script. If your district blocks the Classroom permissions, remove Google Classroom API from Services and deploy again, and email goes back to how it was.

Grading level and what prints on the PDF

Grading level tells Claude to grade more leniently or more strictly. Glows/grows are short bullet points (what's there, what's missing) that print below the rubric. The comment is the note to the student. Each one prints only when turned on. A student's own setting (on their row in the Review tab) beats their class, and a class beats Everyone.

Changing a grading level doesn't change grades that are already done. The Review tab shows who's affected and lets you grade them again.

How to grade

Claude connection

Stored only in this browser. Requests go straight from this page to Anthropic.

Add student work

Drop zip files, PDFs, scans, or docs here or click to choose. Google Classroom zips, scanned stacks, photos, .docx and .pptx all work. Zips inside zips are opened too.

"Detect from file name" files each zip under the period in its name (like Period_5.zip). Use "Mixed stack" for scans with students from several periods.

Sort and grade

Files named for a student are matched to the roster right away. Scans and unnamed files go to Claude, which reads the pages, splits stacks into students (names on the next page included), and then grades each student's work.

Don't have the mailer set up yet?
  1. Go to script.google.com while signed in to your school account and click New project. Name it "Rubric Mailer".
  2. Delete the starter code, paste the script below, and change the SECRET line to a long random phrase of your own. Click Save.
  3. Deploy, then New deployment, then Web app. Set Execute as: Me and Who has access: Anyone. Authorize when asked.
  4. Copy the Web app URL (it ends in /exec) into the box above, put your secret phrase in the key box, and click Check connection.
  5. To post assignments to Google Classroom too, follow the steps under Post to Google Classroom on the Set up tab.
